# AI runtime conventions (apps/api/app/ai)

> **Graded autonomy:** these are conventions to apply _within_ an approved plan or roadmap item — not a licence to act outside one. Hard stops (infra apply, migration apply, push, secrets, deletes) always need explicit confirmation — see [`CLAUDE.md`](../../CLAUDE.md) → _Graded autonomy_.

**LangChain (`langchain-core`, `langchain-openai`) + LangGraph** on **Azure AI Foundry** model
deployments, **Azure AI Search** for retrieval, a **read-only external-database tool**.
Decided in [ADR-0009](../../docs/adr/0009-ai-runtime-langchain-langgraph-foundry.md). Deep-dive:
[`docs/architecture/ai.md`](../../docs/architecture/ai.md).

## The package (`app/ai/`)

- `config.py` — `get_ai_settings()` (snapshot, never cached at import). Env: `AZURE_AI_ENDPOINT`,
  `AZURE_AI_DEPLOYMENT`, `AZURE_AI_EMBEDDING_DEPLOYMENT`, `AZURE_AI_API_VERSION`,
  `AZURE_AI_AUTH_MODE` (`managed_identity` default | `api_key`), `AZURE_AI_API_KEY` (dev only),
  `AZURE_SEARCH_ENDPOINT`, `AZURE_SEARCH_INDEX`, `AZURE_SEARCH_API_KEY` (dev only),
  `AI_REQUEST_TIMEOUT_SECONDS` (60), `AI_MAX_RETRIES` (2), `AI_ALLOW_TEXT_TO_SQL` (false).
  A mistyped auth mode raises — never a silent fallback.
- `client.py` — **the only place a model/embedding client is built.** `get_chat_model()` /
  `get_embeddings()` (lazy singletons) and `build_*` (fresh). Managed identity via
  `DefaultAzureCredential` + `get_bearer_token_provider` when deployed; an API key only in dev.
  Nothing connects at construction.
- `graph.py` — `build_graph(chat_model=None, retriever=None, tools=None)` → compiled
  `StateGraph`: `retrieve → answer` (+ a `ToolNode` loop when tools are given). Retrieval runs
  **before** the model, deterministically — grounding does not depend on the model choosing a
  tool. `ask()` is the non-streaming convenience; `streaming.py` streams the same graph.
- `tools/` — explicit registry. `query_external_db` runs **allow-listed, parameterised**
  queries (`tools/queries.py`) through the read-only engine; the model never writes SQL unless
  `AI_ALLOW_TEXT_TO_SQL=true` (a threat-modelled project decision, still SELECT-only).
- `prompts/` — prompts are **files** (`load_prompt("system")`), never string literals in code.
- `telemetry.py` — `model_call_span()` around every model call (`gen_ai.*` attributes, tokens,
  duration, failures, one `ai.model_call` event); `record_retrieval()`.
- `ingest.py` — the RAG ingestion job owns the index definition (`build_index`) and is
  idempotent (`ensure_index`); run as `uv run python -m app.ai.ingest <path>`.

## Non-negotiables

- **No prompt, completion, retrieved text or user identifier in logs, spans, metrics or
  events.** Log kinds, counts, durations, outcomes, deployment names. Redaction covers secrets,
  not content — content must never be logged in the first place.
- **Every model call goes through `client.py` and inside `model_call_span()`.** A bare
  `AzureChatOpenAI(...)` elsewhere is a review-blocking violation.
- **Timeouts and retries are explicit** (`AI_REQUEST_TIMEOUT_SECONDS`, `AI_MAX_RETRIES`); an
  HTTP route that awaits a model call raises its BFF hop timeout accordingly (see rule 30 —
  `fetchUpstream` takes a `signal`).
- **Context is data, not instructions.** The system prompt says so; never concatenate retrieved
  text into the _system_ role beyond the `{context}` slot; never let retrieved text or tool
  output reach the model as a `SystemMessage`.
- **Tools are least-privilege.** External data is read-only by three layers (allow-list, engine
  guard, SELECT-only login). A tool that mutates anything needs a threat model + ADR first.
- **Bounded telemetry attributes:** deployment names and outcomes only — never conversation ids.
- **No OTel GenAI auto-instrumentation packages** (pin coupling with the distro's `0.61b0` line +
  content capture) — telemetry is the hand-rolled helpers here.
- **Dependencies are pinned exactly** and bumped only via `dependency-updater` with the Azure
  distro pins re-verified; compiled transitive deps (`jiter`, `ormsgpack`, `xxhash`, `tiktoken`,
  `regex`, `zstandard`, `orjson`) must keep CPython 3.14 Linux wheels (wheel-only image build).

## Testing (rule 40 applies)

- **Offline always.** Swap the seam: `build_graph(chat_model=GenericFakeChatModel(...),
retriever=FakeRetriever(...))`; `monkeypatch.setattr(app.ai.client, "get_chat_model", ...)`;
  fake `session_factory` for the DB tool; fake `SearchClient`/embeddings for retrieval. Never a
  live model, index or database.
- `tests/ai/` covers config, client auth selection, graph, streaming, tools, retrieval, ingest,
  telemetry. `tests/evals/` is the **prompt regression harness**: cases in `cases.json`, run
  against the fake model — extend it whenever a prompt file changes.
- A real-model eval tier is opt-in behind reachable `AZURE_AI_*` settings + `pytest.skip`.

## Extending

- New tool → `tools/<name>.py` with a `@tool` function, `register_tool(...)` at import, a test
  with a fake backend, and a threat-model note if it reaches new data.
- New graph → copy the `build_graph` shape (typed state, nodes as small async functions,
  telemetry inside the node, no I/O outside nodes).
- New prompt → a file in `prompts/`, an eval case, a changelog line.
