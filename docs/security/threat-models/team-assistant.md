## 1. Feature summary

Team Assistant is an internal chat assistant: a user opens `/chat`, asks a question, and the api retrieves the top 5
passages of the team's own `docs/**/*.md` from Azure AI Search, asks a `gpt-4.1` deployment on Azure AI Foundry to
answer only from them, streams the answer with `{title, path}` citations, and stores the conversation in Azure SQL.
There is **no authentication**: conversations are shared by every user (ADR-0014) and one operational endpoint,
`POST /v1/admin/ingest`, is guarded by a shared secret header (ADR-0015). **This feature does not introduce auth.**
Adding auth (the planned module is Okta) needs its own ADR and a new threat model (rule 50).

## 4. Data flow and trust boundaries

```
 [Browser]                                   untrusted: question, title, ids, headers (incl. x-trace-id)
    |  TB1  same-origin only; no auth; no rate limit
    v
 [apps/web BFF]  validates + shapes (UUID ids, 4 KB create body, 415, limit 1-100, 8 MiB upstream cap)
    |  TB2  internal network; NO credential between BFF and api; api trusts its network position
    v
 [apps/api FastAPI]  <------ TB6 ------ [operator / script]   POST /v1/admin/ingest, x-admin-key (NOT via the BFF)
    |        |             |
    |TB3     |TB4          |TB7
    v        v             v
 [Foundry: embeddings   [Azure SQL Database           [Azure Monitor]
  + gpt-4.1 chat]        public endpoint, firewall     content-free telemetry
 [AI Search index]       currently ALL IPs (TB4')]

 Corpus path (TB5):  git commit (anyone with commit rights) -> CODEOWNERS/CI gate -> docker build
                     -> /app/corpus in the image -> POST /v1/admin/ingest -> chunk -> embed (Foundry)
                     -> Search index -> retrieved text -> model context  (author text becomes model input)
```

| Boundary | What crosses it                                              | Control today                                                                                        | Not controlled                                                               |
| -------- | ------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| TB1      | questions, titles, ids, query params, headers                | BFF validation helpers (`apps/web/src/lib/conversations-bff.ts`); the ask routes are not written yet | identity, rate, origin of the caller                                         |
| TB2      | JSON bodies, `x-trace-id`                                    | `redirect: 'error'`, JSON-only replies, `{error, trace_id}` shape guard (web 1.2)                    | authenticity of the caller; calls that bypass the BFF and hit the api direct |
| TB3      | question, history, 5 passages out; answer, token counts back | managed identity / dev keys; 60 s timeout, retries (planned in api 4.2)                              | what the provider retains (A7); a poisoned passage as model input            |
| TB4      | rows (all conversation content)                              | TLS (`Encrypt=yes`), `hide_parameters`, driver text hidden from spans (api 1.3, 1.4)                 | network reachability (A8)                                                    |
| TB5      | author-written markdown -> model context                     | CODEOWNERS, baked image (ADR-0013)                                                                   | hostile or accidental content in a merged doc                                |
| TB6      | the shared secret                                            | constant-time compare, fail closed (api 3.3)                                                         | per-person identity, brute-force throttle                                    |
| TB7      | telemetry                                                    | content-free rule; scrubbing hooks                                                                   | a future change that logs content                                            |

## 5. Evidence: what I read in the real code (and what does not exist yet)

Exists today and was read: `apps/api/app/routers/conversations.py`, `app/repositories/conversations.py`, `app/ai/graph.py`,
`app/ai/prompts/system.md`, `app/ai/ingest.py` (a CLI job), `app/ai/tools/retrieve.py`, `app/logging_config.py`,
`apps/web/src/lib/conversations-bff.ts`, `apps/web/src/app/api/v1/conversations/route.ts`, `apps/web/src/components/chat/ChatThread.tsx`.

Does **not** exist yet (designed only): `POST /v1/conversations/{id}/ask`, `.../ask/stream` (api 4.2/4.3),
`POST /v1/admin/ingest` and `INGEST_ADMIN_KEY` (api 3.3), the `/app/corpus` image copy (api 3.4), the BFF ask routes (web 3.1),
the Sources block (web 3.2), and the send flow (web 3.3). The web still contains the template's `/api/v1/assistant/ask[/stream]`
demo routes (removed in web 0.7.0, roadmap web 4.1); the api has no `/v1/assistant` route. Decision numbers cited below are the ones in
ARCHITECTURE.md B8 (1-22); ADR-0013/14/15 are all `Proposed`.

Code facts that drive threats below (so they can be checked later):

- `format_context` (`graph.py:42-49`) inserts each chunk's `source` and `content` **raw** into the system message.
- `Answer.sources` / `unique_sources` (`graph.py:137-143`) are **every retrieved chunk's source**, not the ones the answer cited.
- `build_graph` adds a tool node only when `tools=` is passed (`graph.py:104, 119`); the Team Assistant passes none.
- `load_path` (`ingest.py:142-154`) uses `rglob` + `read_text`, accepts `.md` **and `.txt`**, records `source=file.as_posix()`
  (the path as given, so possibly absolute), and has no symlink or outside-root check.
- `ingest_documents` only **upserts** (`chunk_id = sha1(source#index)`); nothing deletes chunks of removed or shortened files.
- `AzureSearchRetriever` calls the sync `SearchClient.search` through `asyncio.to_thread` with **no explicit timeout**
  (`retrieve.py:99-116`); it passes `search_text` and `select` only (no `filter=`, so no OData injection surface today).
- `DEFAULT_REDACTED_FIELDS` (`logging_config.py:51-69`) does **not** include `x_admin_key`, `admin_key` or `ingest_admin_key`.
- `ChatThread.tsx` renders message text as a React text node (no markdown, no HTML); the web sets **no Content-Security-Policy**
  (no match in `apps/web` config).
- The api reads the whole request body before validating it (api 2.1 notes); the BFF caps only the create body (4 KB).
- No roadmap item in `roadmaps/api`, `roadmaps/web` or `roadmaps/infra` mentions a rate limit or throttle (`roadmaps/infra/ROADMAP.md` has no items).

## 6. Threat register

**Reading the tables.** `L` = likelihood, `I` = impact (H/M/L), in the stated assumptions. **Layer** says where the control
works: **code** (enforced by the program and testable), **prompt** (relies on the model following instructions; not a
guarantee), **process** (people or repo workflow), **network** (infrastructure). **Status**: `PLANNED` = a roadmap item
covers it (its id is named; it is not implemented unless that item is `done`), `PARTIAL`, `ACCEPTED` (reason and who),
`GAP` (no item yet, see section 8). Roadmap ids: `api N.N`, `web N.N`. Nothing here is rated "low" without a named control.

Currently `done`: api 1.1 to 1.5, 2.1; web 1.1 to 1.2, 2.1, 2.2; api 4.1 (prompt and offline evals). Everything else named is `todo`.

**Ingress timeout.** Azure Container Apps ingress has a fixed HTTP request timeout of **240 seconds**
([Microsoft Learn](https://learn.microsoft.com/en-us/azure/container-apps/ingress-overview)); it is not configurable, so nothing in this
repository can raise it. The api's worst case for one answer (60 s model timeout × 3 attempts, plus two 30 s retrieval steps) is about 4
minutes, which is the same size. Proposed: the page uses the **streaming** route (the first bytes arrive within seconds); and the api's
worst case is brought inside the limit by lowering the default model retries from 2 to 1 (worst case 180 s): item **api 5.6** (implemented). The
BFF → api hop timeout stays at 5 minutes (it is only an upper bound).
